**🧠 MemoryCardMe**
MemoryCardMe is a fun and simple memory card matching game built with React. Flip cards and match all the pairs within a limited number of moves!
Visit https://memorygame-4z4.pages.dev/ to Play


**🎮 How to Play**
You're given a grid of hidden cards.

Click a card to flip it over.

Flip another card and try to match it.

If the cards match, they stay flipped.

If they don’t, they flip back over.

Match all card pairs before you run out of moves!

**⚙️ Features**
🔄 Smooth flip animations

⏳ Limited move counter for added challenge

🔁 Easy to restart and replay

💻 Built with React functional components and hooks
